# نصب نسخه ۶۴ در cPanel

این نسخه صفحه تنظیمات طرح‌های وام را بازطراحی می‌کند، انتخاب تکی و چندتایی و عملیات گروهی امن را اضافه می‌کند و متن‌ها و نمایش بخش ثبت رسید یا فاکتور را اصلاح می‌کند.

## پیش‌نیاز

- نسخه ۶۳ باید قبلاً نصب شده باشد.
- فایل `update_customer_workflow_v64.py` را کنار `manage.py` قرار دهید.
- نصب‌کننده از کدها و دیتابیس SQLite نسخه پشتیبان می‌سازد.

## اجرا

در **Setup Python App** و بخش **Execute python script** اجرا کنید:

```text
update_customer_workflow_v64.py
```

خروجی موفق:

```text
SUCCESS: V64 installed
```

## کنترل بعد از نصب

1. صفحه تنظیمات طرح‌های وام باید به‌صورت فهرست تک‌ستونه و خلاصه نمایش داده شود.
2. هر طرح باید چک‌باکس مستقل و نوار بالا باید گزینه «انتخاب همه» داشته باشد.
3. فعال‌سازی، غیرفعال‌سازی، حذف و بازکردن ویرایش باید برای یک یا چند طرح انتخاب‌شده کار کند.
4. طرحی که در قرارداد استفاده شده است حذف نمی‌شود و پیام مناسب نمایش داده می‌شود.
5. عنوان بخش مدارک پرداخت باید «ثبت رسید یا فاکتور پرداخت» باشد و فایل و توضیحات به‌صورت جدا و فارسی نمایش داده شوند.
