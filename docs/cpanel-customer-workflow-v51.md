# اصلاح نمایش فارسی و جداسازی برچسب‌ها — نسخه ۵۱

در مؤلفه مشترک فرم، عنوان فیلد و واژه «اختیاری» بدون مرز واقعی کلمه در دو span مجاور ساخته می‌شدند. فاصله CSS به‌تنهایی می‌تواند شکل اتصال حروف فارسی در مرز دو متن را نامناسب کند. اکنون عنوان در span مستقل قرار دارد، قبل از نشان وضعیت فاصله واقعی وجود دارد و نشان وضعیت با جداسازی جهت و نمایش مستقل رندر می‌شود. این اصلاح در تمام فرم‌هایی که مؤلفه مشترک را استفاده می‌کنند اعمال می‌شود، شامل پنجره مشخصات و فرم‌های تنظیمات.

اصلاح نمایش مشترک در صفحات اصلی، ورود، تأیید دومرحله‌ای و پنل ادمین نیز قرار دارد. «ي/ى/ك» در متن نمایشی به «ی/ک» تبدیل می‌شوند و حروف با شکل‌های Unicode نمایشی قدیمی به حرف پایه فارسی برمی‌گردند. اتصال اجباری و کشیده اضافیِ کنار حروف فارسی اصلاح می‌شود؛ نیم‌فاصله صحیح واژه‌هایی مانند «می‌شود» و اتصال ایموجی‌ها حفظ می‌شود. محتوای پویا، برچسب‌ها، عنوان‌ها و متن راهنمای ورودی‌ها نیز پوشش داده می‌شوند. فاصله‌گذاری لاتین روی عنوان فارسی ستون‌ها در نمایش گوشی حذف شده است.

اصلاح حروف مربوط به نمایش است؛ مقادیر فرم، شناسه گزینه‌ها و داده ذخیره‌شده حفظ می‌شوند. متن قابل ویرایش، کد، مقادیر فنیِ علامت‌گذاری‌شده و نقل‌قول مشخص‌شده با زبان عربی تغییر داده نمی‌شوند. فقط متن نمایشی گزینه دارای مقدار مستقل اصلاح می‌شود؛ گزینه‌ای که مقدار ارسالی‌اش از متن خودش گرفته می‌شود دست‌نخورده باقی می‌ماند.

چند نگارش ناهماهنگ ثابت هم اصلاح شد: «تأیید» در ورود دومرحله‌ای، مرخصی، راهنمای دسترسی و عناوین تنظیمات، و «به‌روزرسانی» در صفحه جزئیات. migration جدید `hr.0011` فقط عنوان نمایشی وضعیت‌های مرخصی را هماهنگ می‌کند؛ کلیدهای `pending/approved/...` حفظ شده‌اند.

۸۰۱ آزمون سراسری موفق بود. Chromium در ۱۲ حالت صفحه/اندازه با عرض‌های ۳۲۰، ۳۹۰، ۷۶۸ و ۱۴۴۰ بررسی شد. آزمایش متن پویا، حروف نمایشی، حفظ نیم‌فاصله و ایموجی، حفظ شناسه و مقدار فرم، راهنمای ورودی و نمایش صحیح نشان‌های مخفی موفق بود. مرز عنوان و نشان اختیاری از HTML واقعی فرم، بدون اجرای JavaScript برنامه هم بررسی شد. نصب تجمعی روی نسخه ۵۰ و اجرای دوباره، داده‌ها و تنظیمات را حفظ کرد.

[نمونه خروجی اصلاح‌شده](settings-review-v51.html)

برای نصب، `scripts/update_customer_workflow_v51.py` را کنار `manage.py` قرار دهید و با Python محیط مجازی اجرا کنید:

```sh
python update_customer_workflow_v51.py
```

پس از `SUCCESS` برنامه را Restart کنید. نصب‌کننده تجمعی است و نسخه پشتیبان می‌گیرد. این نسخه هنوز روی هاست کاربر نصب نشده است.
