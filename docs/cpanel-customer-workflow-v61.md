# نصب نسخه ۶۱ در cPanel

این نسخه فرمول مالی باشگاه مشتریان را اصلاح می‌کند، هزینه پیش‌فرض باشگاه را روی یک میلیون تومان می‌گذارد و بارگذاری خصوصی فاکتور/رسید را برای مابه‌التفاوت، هزینه باشگاه، اقساط و آگهی اضافه می‌کند. تنظیمات طرح‌های وام نیز به صفحه‌ای مستقل زیر «مرکز مشتریان» منتقل شده و چاپ تمیز، تاریخ شمسی سررسید و چینش هماهنگ جدول‌ها فعال می‌شود.

## پیش‌نیاز

- نسخه ۶۰ باید قبلاً نصب شده باشد.
- فایل نصب‌کننده را کنار `manage.py` قرار دهید.
- قبل از اجرا از محیط آزمایشی خارج نشوید.

## اجرا

از بخش **Setup Python App**، در کادر **Execute python script** فقط نام فایل زیر را وارد و اجرا کنید:

```text
update_customer_workflow_v61.py
```

اگر فایل را داخل پوشه `scripts` گذاشته‌اید، ابتدا آن را کنار `manage.py` منتقل کنید. نصب‌کننده خودش از کدها و دیتابیس SQLite نسخه پشتیبان می‌گیرد، مهاجرت‌ها و کنترل سلامت را اجرا می‌کند و Passenger را ری‌استارت می‌کند.

## نتیجه مورد انتظار

آخر خروجی باید شامل این عبارت باشد:

```text
SUCCESS: V61 installed
```

لاگ کامل در مسیر `logs/workflow_v61_update.log` و نسخه پشتیبان در `backups/workflow-v61-*` ذخیره می‌شود.

## کنترل سریع بعد از نصب

1. در باشگاه مشتریان یک ارزیابی باز کنید؛ مبلغ وام، سقف خرید وام، خرید اصلی و مابه‌التفاوت باید جدا نمایش داده شوند.
2. هزینه باشگاه باید به‌صورت پیش‌فرض `1,000,000` تومان باشد و امکان ویرایش داشته باشد.
3. بعد از ثبت قرارداد، برای مابه‌التفاوت، هزینه باشگاه و اقساط امکان ثبت فاکتور یا رسید وجود داشته باشد.
4. در ویرایش آگهی انتخاب‌شده نیز بخش فاکتور یا رسید پرداخت نمایش داده شود.
5. از زیرمنوی «مرکز مشتریان ← تنظیمات طرح‌های وام» بتوانید مبلغ وام، سقف خرید، اقساط و شرایط هر طرح را ویرایش کنید.
6. در ثبت پرداخت، انتخاب «قسط» باید اولین قسط بدون رسید را با سررسید شمسی آماده کند و پس از ثبت، رکورد تکراری نسازد.
7. دکمه چاپ در قرارداد باشگاه و فهرست تبلیغات باید خروجی سربرگ‌دار «شرکت دیجیران» تولید کند.
