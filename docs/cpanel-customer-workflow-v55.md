# اتصال واقعی ملی‌پیامک — V55

این نسخه اتصال REST ملی‌پیامک را مطابق راهنمای رسمی `webservice-rest.pdf` فعال می‌کند. نشانی ارسال فقط دامنه رسمی زیر است:

`https://rest.payamak-panel.com/api/SendSMS/SendSMS`

## امکانات

- بررسی واقعی اتصال با متد `GetCredit`، بدون ارسال پیامک؛
- ارسال واقعی پیامک از قالب انتخاب‌شده و متن دلخواه؛
- ثبت مقصد، متن نهایی، نتیجه، کاربر و شناسه دریافتی سرویس در سابقه عملیات؛
- جلوگیری از ارسال دوباره همان درخواست هنگام دوبار کلیک یا ارسال مجدد فرم؛
- ثبت خطای امن بدون ذخیره یا نمایش نام کاربری و API Key؛
- مجوز مستقل `communications.send_live` که به‌صورت پیش‌فرض فقط مدیر کل دارد و از دسترسی پیشرفته قابل واگذاری است.

## تنظیم امن هاست

کلیدی که در گفتگو یا هر محل عمومی فرستاده شده باید از پنل ملی‌پیامک باطل و دوباره ساخته شود. مقدار جدید را داخل کد، فرم CRM، Git یا فایل نصب قرار ندهید. در فایل `.env` کنار `manage.py` این دو خط را با مقادیر واقعی قرار دهید:

```env
MELLIPAYAMAK_USERNAME=YOUR_PANEL_USERNAME
MELLIPAYAMAK_API_KEY=YOUR_NEW_API_KEY
```

در صفحه «مدیریت پیام‌رسانی ← پیامک ← پیکربندی» نیز خط اختصاصی فرستنده را وارد کنید. نام متغیرها و نشانی رسمی به‌صورت خودکار تنظیم می‌شوند. اگر پنل خطای `-109` برگرداند، IP خروجی هاست را در «توسعه‌دهندگان ← IPهای مجاز API» ملی‌پیامک ثبت کنید.

## نصب در cPanel

فایل `scripts/update_customer_workflow_v55.py` را کنار `manage.py` بارگذاری و با Python برنامه اجرا کنید. پس از پیام `SUCCESS`، برنامه را Restart کنید. نصب‌کننده از کد و SQLite پشتیبان می‌گیرد، مهاجرت‌ها و بررسی‌ها را اجرا می‌کند و فایل `.env` را تغییر نمی‌دهد.

برای آزمایش امن، ابتدا «بررسی اتصال» را اجرا کنید. پس از تأیید، یک شماره تحت کنترل خودتان و متن کوتاه را انتخاب و دکمه «ارسال واقعی پیامک» را بزنید؛ این دکمه واقعاً از اعتبار پنل کم می‌کند.
