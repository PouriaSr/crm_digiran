# نصب نسخه ۶۳ در cPanel

این نسخه ارزیابی هوشمند باشگاه مشتریان را قابل ویرایش و اجرای مجدد می‌کند، نمایش قرارداد فعال را خلوت‌تر می‌سازد و کنترل‌های دسترسی باشگاه را در سطوح دسترسی پیشرفته کامل می‌کند.

## پیش‌نیاز

- نسخه ۶۲ باید قبلاً نصب شده باشد.
- فایل `update_customer_workflow_v63.py` را کنار `manage.py` قرار دهید.
- نصب‌کننده از کدها و دیتابیس SQLite نسخه پشتیبان می‌سازد.

## اجرا

در **Setup Python App** و بخش **Execute python script** این نام را اجرا کنید:

```text
update_customer_workflow_v63.py
```

خروجی موفق باید شامل عبارت زیر باشد:

```text
SUCCESS: V63 installed
```

لاگ نصب در `logs/workflow_v63_update.log` و نسخه پشتیبان در `backups/workflow-v63-*` قرار می‌گیرد.

## کنترل بعد از نصب

1. در قرارداد فعال، دکمه «ارزیابی مجدد» باید برای کاربر دارای هر دو مجوز ارزیابی و ویرایش قرارداد دیده شود.
2. مبلغ وام پیشنهادی و پیش‌پرداخت قبلی باید داخل پنجره ارزیابی پر شده و قابل تغییر باشند.
3. انتخاب پیشنهاد جدید باید همان قرارداد را به‌روزرسانی کند و پرداخت‌ها و رسیدهای قطعی را نگه دارد.
4. کارت قرارداد فعال باید طرح وام، گوشی و نوع تحویل را در سه بخش خوانا و جزئیات رتبه و ضمانت را در یک نوار خلاصه نشان دهد.
5. در سطوح دسترسی پیشرفته، موارد تب باشگاه، ارزیابی، ثبت قرارداد، ویرایش، پرداخت و مدیریت طرح‌های وام باید جداگانه قابل فعال یا غیرفعال‌کردن باشند.
