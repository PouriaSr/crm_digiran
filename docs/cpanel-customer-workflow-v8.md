# اصلاح فیلتر تاریخ و اعتبارسنجی تماس — V8

فایل `scripts/update_customer_workflow_v8.py` را با Download raw file دانلود، کنار `manage.py` در `crm_digiran_test` آپلود و در Execute python script اجرا کنید:

```text
update_customer_workflow_v8.py
```

پس از SUCCESS برنامه را Restart و صفحه را Ctrl+F5 کنید. نصب مستقل است، پشتیبان کد و SQLite می‌گیرد و تنظیمات محیط و Passenger را حفظ می‌کند. گزارش در `logs/workflow_v8_update.log` است.

بازه تاریخ به‌صورت پیش‌فرض روی **تاریخ ثبت مشتری** اعمال می‌شود. برای فیلتر تسک‌ها، **نزدیک‌ترین پیگیری** را انتخاب کنید؛ این گزینه فقط مشتری دارای پیگیری باز در بازه انتخاب‌شده را نشان می‌دهد. توضیح مبنای انتخابی کنار فیلتر نمایش داده می‌شود. اعداد فارسی/عربی و نشانه‌های جهت متن در تاریخ پشتیبانی می‌شوند.

شماره تماس نامعتبر هنگام تایپ/خروج از فیلد خطا می‌گیرد و ثبت تا ورود دقیقاً ۱۱ رقم ممکن نیست. فیلدهای نام، شماره، نوع تماس، منبع تماس، هدف، وضعیت، تحلیل مشتری، شرایط درخواستی و شرح مکالمه اجباری‌اند؛ پیش‌فرض معتبر فیلدها پذیرفته می‌شود. منبع تماس باید از منابع فعال انتخاب شود. اعتبارسنجی سمت سرور نیز اعمال می‌شود.

بخش **اقدام بعدی** همان منطق قبلی را دارد: تیک‌ها اختیاری‌اند؛ قصد خرید، پیگیری را فعال می‌کند؛ تاریخ و ساعت فقط در صورت نیاز به پیگیری الزامی‌اند. پیامک همچنان آزمایشی است.
