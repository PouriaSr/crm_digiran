# اعداد یکسان در ورود اطلاعات، اعداد فارسی در نمایش (V11)

در فرم‌ها، فیلترها و جستجوهای سیستم، ارقام فارسی، انگلیسی و عربی به یک مقدار تبدیل می‌شوند. صفر ابتدای شماره تماس و کد ملی حفظ می‌شود؛ مبلغ‌هایی مانند `۱٬۲۳۴٫۵۰` و `1,234.50` نیز یکسان پردازش می‌شوند. جستجو در مشتریان، تماس‌ها، کالاها، فاکتورها، تبلیغات، منابع انسانی و گزارش‌ها، رکوردهای قدیمی دارای ارقام ترکیبی را هم پیدا می‌کند؛ داده‌های قبلی بازنویسی نمی‌شوند.

نمایش اعداد در فرم‌ها، جدول‌ها، نمودارها، مودال‌ها و چاپ فارسی است. یک فونت کوچک فقط برای رقم‌ها در قالب‌ها قرار دارد؛ نمایش رقم فارسی به CDN یا اجرای `collectstatic` نیاز ندارد. مقدار داخلی فیلدهای عددی برای محاسبه و اعتبارسنجی مرورگر، استاندارد باقی می‌ماند. رمز عبور، نام کاربری، ایمیل، URL، توکن و کلیدهای حساس خودکار تغییر نمی‌کنند. محتوای فایل‌های آپلودشده و بدنه‌های JSON دست‌نخورده‌اند. ورودی HTTP فرم‌ها و QueryString نرمال می‌شود؛ این قابلیت، داده‌هایی را که مستقیماً از ORM یا API JSON نوشته شوند تغییر نمی‌دهد.

## نصب در cPanel

۱. فایل `scripts/update_customer_workflow_v11.py` را از GitHub با گزینه **Download raw file** دانلود کنید.

۲. آن را کنار `manage.py` در `/home/digiran5/crm_digiran_test` آپلود کنید.

۳. در بخش Python App، با **Execute python script** فایل `update_customer_workflow_v11.py` را اجرا کنید.

۴. پس از مشاهده `SUCCESS`، برنامه را **Restart** کنید و در مرورگر **Ctrl+F5** بزنید.

نصب‌کننده مستقل و شامل تغییرات نسخه‌های قبلی است. فایل‌های برنامه و SQLite پیش از تغییر پشتیبان‌گیری می‌شوند؛ `.env`، Passenger و `.htaccess` حفظ می‌شوند. هیچ مهاجرت جدیدی برای این قابلیت نیاز نیست. فایل‌های دارای تغییر ناشناخته پیش از نوشتن فایل‌های برنامه باعث توقف نصب می‌شوند. گزارش در `logs/workflow_v11_update.log` قرار دارد.

## یادداشت فنی

`crm/numerals.py` منطق مشترک ارقام را نگه می‌دارد. Middleware پیش از اعتبارسنجی فرم و CSRF، فقط مقدارهای غیرحساس GET/POST را تبدیل می‌کند و کلیدها و لیست مقدارها را حفظ می‌کند. جستجوی ارقام از عبارت‌های پارامتری `Replace` روی ستون‌ها استفاده می‌کند و شرط‌های مالکیت و دسترسی را تغییر نمی‌دهد؛ جستجوی بدون رقم همان SQL قبلی را دارد.

فونت رقمی `CRM Persian Digits` از [Vazirmatn v33.003](https://github.com/rastikerdar/vazirmatn/tree/v33.003) با تغییر نگاشت ارقام و حذف سایر نویسه‌ها ساخته شده است. مجوز و کپی‌رایت در [vazirmatn-OFL.md](licenses/vazirmatn-OFL.md) قرار دارد. هیچ وابستگی جدیدی در زمان اجرای برنامه لازم نیست.
