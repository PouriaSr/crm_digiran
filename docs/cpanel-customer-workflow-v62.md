# نصب نسخه ۶۲ در cPanel

این نسخه ظاهر فرم‌های باشگاه مشتریان را با فرم‌های اصلی CRM یکپارچه می‌کند، برای فهرست‌ها و جدول‌های استاندارد کل سیستم خروجی چاپی می‌سازد و امکان ویرایش کنترل‌شده قرارداد باشگاه را اضافه می‌کند.

## پیش‌نیاز

- نسخه ۶۱ باید قبلاً نصب شده باشد.
- فایل `update_customer_workflow_v62.py` را کنار `manage.py` قرار دهید.
- نصب‌کننده برای کدها و دیتابیس SQLite نسخه پشتیبان می‌سازد.

## اجرا

در **Setup Python App** و بخش **Execute python script** این نام را اجرا کنید:

```text
update_customer_workflow_v62.py
```

خروجی موفق باید شامل عبارت زیر باشد:

```text
SUCCESS: V62 installed
```

لاگ نصب در `logs/workflow_v62_update.log` و نسخه پشتیبان در `backups/workflow-v62-*` قرار می‌گیرد.

## کنترل بعد از نصب

1. در تب باشگاه مشتریان، فرم پرداخت باید در دسکتاپ منظم و در گوشی تک‌ستونه باشد.
2. آپلود فایل باید با دکمه فارسی «انتخاب فایل» و نام فایل انتخاب‌شده نمایش داده شود.
3. کنار قرارداد فعال، گزینه «ویرایش قرارداد» برای کاربران دارای مجوز دیده شود.
4. تغییر هزینه باشگاه، نوع تحویل، طرح یا گوشی باید پرداخت‌های قطعی را حفظ و فقط برنامه آینده را همگام کند.
5. فهرست‌ها و جدول‌های استاندارد باید دکمه «چاپ فهرست» داشته باشند؛ خروجی چاپ شامل نام شرکت، عنوان، تاریخ شمسی، تعداد ردیف و سرستون تکرارشونده است.
