# نصب نسخه ۶۵ در cPanel

این نسخه نمایش و محاسبه علامت‌دار مابه‌التفاوت وام را اضافه می‌کند و شرط شغل طرح وام را به گزینه‌های چندانتخابیِ مشترک با تب پرونده متصل می‌کند.

## پیش‌نیاز

- نسخه ۶۴ باید قبلاً نصب شده باشد.
- فایل `update_customer_workflow_v65.py` را کنار `manage.py` قرار دهید.
- نصب‌کننده پیش از تغییر کد، از فایل‌ها و دیتابیس SQLite نسخه پشتیبان می‌سازد.

## اجرا

در **Setup Python App** و بخش **Execute python script** اجرا کنید:

```text
update_customer_workflow_v65.py
```

خروجی موفق:

```text
SUCCESS: V65 installed
```

## کنترل بعد از نصب

1. مابه‌التفاوت مثبت باید با `+` سبز و عنوان «قابل دریافت از مشتری» نمایش داده شود.
2. مابه‌التفاوت منفی باید با `−` قرمز و عنوان «غیرفعال برای دریافت و ثبت رسید» نمایش داده شود.
3. برای مابه‌التفاوت منفی نباید ردیف پرداخت یا محل بارگذاری رسید ایجاد شود.
4. در تنظیمات طرح وام، «شغل‌های مجاز متقاضی» باید به‌صورت چندانتخابی و با گزینه‌های همان فیلد شغل تب پرونده نمایش داده شود.
