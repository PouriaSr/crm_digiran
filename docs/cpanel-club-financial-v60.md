# نصب نسخه ۶۰ — خلاصه مالی باشگاه مشتریان

این نسخه پس از نسخه ۵۹ اجرا می‌شود و سقف خرید وام، پیش‌پرداخت، مابه‌التفاوت، هزینه باشگاه و جمع کل تعهد مشتری را در پیشنهاد و قرارداد نمایش می‌دهد.

1. فایل `scripts/update_customer_workflow_v60.py` را کنار `manage.py` آپلود کنید.
2. در **Setup Python App** و بخش **Execute Python Script** اجرا کنید:

   ```text
   update_customer_workflow_v60.py
   ```

3. پس از پیام `SUCCESS: V60 installed` صفحه را با `Ctrl+F5` تازه‌سازی کنید.

فرمول ثبت‌شده:

```text
سقف خرید وام + پیش‌پرداخت + مابه‌التفاوت + هزینه باشگاه = جمع کل تعهد مشتری
```

این مبالغ هنگام ثبت انتخاب در قرارداد ذخیره می‌شوند. migration نسخه ۶۰ همین اطلاعات را برای قراردادهای قبلی نیز محاسبه و تکمیل می‌کند. گزارش اجرا در `logs/workflow_v60_update.log` و نسخه پشتیبان در `backups/workflow-v60-*` قرار می‌گیرد.
